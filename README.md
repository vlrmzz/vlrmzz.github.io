# vlrmzz.github.io

The personal site of Vlr Mzz: [vlrmzz.github.io](https://vlrmzz.github.io).

Plain HTML and CSS, with no build step. GitHub Pages serves the files as they are
(`.nojekyll` turns Jekyll off).

- `index.html`: home
- `about/`: who I am, education, grants, contact
- `work/`: the case studies
- `projects/`: personal projects
- `writing/`: experiment write-ups. Their code is in
  [ai-claims-experiments](https://github.com/vlrmzz/ai-claims-experiments).
- `archive/` and `2021/`, `2022/`: data-science posts from 2021-22
- `assets/site.css`, `assets/site.js`: the one stylesheet and the one script
